## 2026-10-04 — Dọn warning Expo Web về shadow và focus/aria-hidden

Các warning console trên Mobile/Expo Web được xử lý ở nguồn thay vì ẩn bằng LogBox.

- tab bar chuyển từ nhóm style `shadowColor/shadowOpacity/shadowRadius/shadowOffset` đã deprecated trên React Native Web sang `boxShadow`, vẫn giữ `elevation` cho Android;
- `ProductCard` bỏ legacy shadow props ở chấm màu và dùng `boxShadow` tương thích Expo Web;
- các entry point điều hướng phổ biến từ Home (`CategoryStrip`, `DiscoveryTiles`) và `ProductCard` gọi `releaseWebFocus()` trước `router.push`, tránh để nút vừa bấm giữ browser focus khi Expo Router đánh dấu screen cũ `aria-hidden`;
- thử nghiệm thêm `screenListeners.transitionStart` ở Root `Stack` đã được revert ngay sau đó vì xuất hiện runtime regression trong phiên kiểm thử; không dùng global navigation listener chỉ để dọn warning;
- không thay route contract, API, backend, database hoặc logic commerce;
- nếu warning `Blocked aria-hidden ... descendant retained focus` tái xuất hiện ở một flow khác, cần xử lý cục bộ tại interaction gây transition thay vì gắn listener global vào navigator.
