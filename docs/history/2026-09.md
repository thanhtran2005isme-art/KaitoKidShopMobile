## 2026-09-21 — MariaDB runtime verification

The local database environment was verified as:

- MariaDB `10.4.32`
- database `kaitokid`
- 51 base tables
- application user `kaitokid@localhost`

A password mismatch initially caused MariaDB error 1045 and API.Customer EF/Pomelo failures.

The durable fix was not to commit a real password. Instead, a gitignored `backend/db.local.bat` workflow was added and loaded by the Windows launchers.

## 2026-09-21 — Expo/mobile startup fixes

Several separate launcher issues were identified and fixed:

1. Expo terminal closed too quickly to read failures.
2. Nested Windows CMD quoting produced `The syntax of the command is incorrect.`.
3. `node_modules` existed while `node_modules/.bin/expo.cmd` was missing, so the old script incorrectly skipped dependency installation.

The current launcher checks for the real Expo executable, installs dependencies if needed, and runs the local CLI.

## 2026-09-21 — Verified end state

After the DB and Expo launcher fixes:

- API.Auth started successfully.
- API.Customer connected to MariaDB.
- Expo/Metro started successfully.
- The Expo Web build rendered the mobile application.
- Categories and product data loaded from the backend on the mobile home screen.

This verified state was promoted into `docs/AI_HANDOFF.md`.


## 2026-09-21 — Expo Web media/console cleanup

Investigated browser console noise from the mobile Expo Web build.

- Existing slider files `slide_1.jpg`, `slide_2.jpg`, and `slide_3.jpg` were present in `apps/web/public` but were not exposed by API.Customer on port 5265.
- Product seed URLs such as `/products/jean-nu-1.jpg` referenced files that did not exist in either the current repository or the pre-refactor tree.
- API.Customer was updated to serve `apps/web/public` as shared media and to return a branded placeholder for missing seeded product images.
- The React Native Web `pointerEvents` deprecation message was confirmed as upstream navigation noise; a narrow development-only warning filter was added rather than forcing a breaking React Navigation major-version upgrade.
