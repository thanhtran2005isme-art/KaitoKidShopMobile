# KaitoKidShop Web

React + TypeScript + Vite frontend nằm trong `apps/web`.

## Cài đặt

```bash
cd apps/web
npm install
```

## Chạy development

```bash
npm run dev
```

## Build

```bash
npm run build
```

Backend nằm tại `../../backend`.

Launcher Windows từ root:

```bat
scripts\run-web.bat
```

README dự án cũ được giữ tại `README.legacy.md`; README mặc định của Vite được giữ tại `README.vite.md`.
